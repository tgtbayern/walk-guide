# Walk 随身导游

走到哪讲到哪：地图上显示你的位置和附近景点的照片，点哪个就讲哪个；打开自动讲解后，边走边开车一段接一段地讲。Claude 写讲稿，OpenAI 朗读。

**打开使用：** https://tgtbayern.github.io/walk-guide/

## 功能

- **地图**：地图铺满屏幕，讲解在可拖动的面板上（三档高度，点抓手切换）。附近景点以圆形照片标在地图上，点照片就开讲。
- **讲讲我附近 / 自动讲解**：先查维基百科和 OpenStreetMap，只讲附近真实存在、真正重要的地方；附近没什么可讲时，往外扩展到这条路、这座城、这个州。说过的内容不再重复。
- **正在讲**：底部常驻播放卡片，显示当前话题，可暂停、重播、拖动进度、切换语速。
- **语音提问**：输入框右边的麦克风。有 OpenAI key 时录音后用 gpt-4o-mini-transcribe 转文字（装成 App 后也能用），否则用系统语音识别；说完停顿一下自动发送。提问时讲解自动暂停。
- **追问**：地图和展板各有自己的对话，接着问会带上前面的内容。
- **展板**：拍一张或几张展板，可框选，选「按句翻译」或「精炼讲解」，整理成口语讲给你听。
- **设置**：兴趣方向、讲解风格、自定义要求、语速、语音引擎和音色。深色模式跟随系统，地图同步变暗。

## 使用方法

1. 用手机 Safari 打开上面的网址，「分享 → 添加到主屏幕」装成 App。
2. 填入 Anthropic API key（必填）和 OpenAI API key（朗读和语音输入用，可不填）。
3. 允许定位和麦克风。

## 注意

- API key 不在代码里，只存在这台手机上，可选记住 1 / 7 / 30 天，到期自动删除。
- 页面需要保持在前台，锁屏后定位会停。
- 讲解由 AI 结合公开资料生成，具体数字和年份请以权威资料为准。

## 技术

单个 `index.html`，无后端：Leaflet + OpenStreetMap 底图，Geolocation API，维基百科 GeoSearch / Overpass / Nominatim，Claude API（流式），OpenAI `tts-1` 朗读、`gpt-4o-mini-transcribe` 语音转文字。
